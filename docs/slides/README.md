# Slides

The presentation deck for Ansera (CS5224 Group 20), copied from the `cs5224-presentation` repository.

- `index.html`: the animated slides with speaker notes. Open it in a browser; no build step or server needed.
  - → or Space for the next build, ← to go back, **P** to present, **N** for the notes, **O** for an overview of every slide.
- `slides.pdf`: the same slides as a PDF.
- `assets/`: the deck's styles and scripts.

GitHub Pages publishes this folder (and only this folder) through `.github/workflows/pages.yml` on every push to `main` that changes it. To update the slides, copy the new `index.html`, `assets/` and `slides.pdf` from `cs5224-presentation` here.
