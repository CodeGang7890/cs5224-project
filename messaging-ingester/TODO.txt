Steps (when sending messages):
1. Customer -> Meta: Customer sends a message to the business's WA number.
2. Meta -> Messaging Ingester: In developer dashboard, register a URL. Meta sends a HTTP POST for every incoming message e.g.,
```json
{
    "phone_number": ...,
    "from": ...,
    "text": ...
}
```
Messaging Ingester check request came from Meta, pull out information, publish to Pub/Sub, return Meta 200 OK right away.
3. Pub/Sub -> Messaging Service -> Database
4. Messaging Service -> Whatsapp API -> Customer
5. Chat Sandbox connects to Configuration Service (which reads the Database)

Example call:
curl -i -X POST `
     https://graph.facebook.com/v25.0/{phone_number_id}/messages `
     -H 'Authorization: Bearer {access_token}' `
     -H 'Content-Type: application/json' `
     -d '{
        \"messaging_product\": \"whatsapp\",
        \"to\": \"6587438485\",
        \"type\": \"template\",
        \"template\": {
            \"name\": \"hello_world\" ,
            \"language\": { \"code\": \"en_US\" }
        }
    }'
Note: Phone number ID is different than phone number, given by Meta.
